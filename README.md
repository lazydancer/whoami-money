# whoami — issues

This is the place to report a problem with [whoami](https://whoami.money), the
offline-first personal finance tracker, or to suggest something it should do.
The app's source is not published here; this repository exists so that reports
have a home and so you can see what has already been reported and what has
been fixed.

## Before you write

- **Never paste financial data.** No journal CSV, no bank statement, no account
  key, no share code, no screenshot with real numbers in it. A report that
  needs data can usually be reproduced with the app's built-in sample journal
  ("Look around first" on the start screen), or with a few invented rows.
- Have three things ready: the app's version (Journal → Guide, at the bottom),
  your browser and its version, and the exact steps you took.
- Check the open issues first. Add to an existing one rather than opening a
  twin.

## Which form

- **Bug** — something the app did that it should not have.
- **Import problem** — a bank file or paste that the app read wrongly or refused.
  Say which bank and which format (CSV, OFX, QFX); never attach the file.
- **Idea** — something the app does not do and you think it should.

Security problems go by email, not here — see [SECURITY.md](SECURITY.md).

## What happens next

Reports are read by one person, in order. A confirmed bug gets the `bug`
label and a note when it ships; an idea gets a reply about whether it fits the
app's direction. The app's principle is that a personal ledger is yours, kept
on your device, and every change is judged against that first.
